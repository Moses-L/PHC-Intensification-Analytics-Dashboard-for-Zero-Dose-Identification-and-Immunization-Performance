# PHC-Intensification-Analytics-Dashboard-for-Zero-Dose-Identification-and-Immunization-Performance
PHC Intensification Analytics Dashboard for Zero-Dose Identification and Immunization Performance is a real-time, data-driven analytics solution designed to improve routine immunization performance and zero-dose identification in conflict- and resource-constrained settings. Using integrated DHIS2, campaign, and field monitoring data, the dashboard enabled rapid tracking of immunization coverage, Vaccine Cold Chain Management (VCM) performance, and sub-national disparities at state and LGA levels.
The solution combined ODK configuration, interactive Power BI dashboards, geospatial analytics, and data quality reviews to support evidence-based microplanning during emergency immunization campaigns and polio SIAs across fragile and conflict settings and high-priority regions in Yobe and Borno State Nigeria. By translating complex datasets into actionable insights, the project strengthened decision-making for UNICEF, state immunization teams, and LGA officers facilitating timely corrective actions, targeted outreach to underserved populations, and improved accountability across the immunization delivery chain.
